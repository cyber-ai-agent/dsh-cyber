# 受控网页浏览与权限体验 V1

## 目标

角色读取公开网页时使用宿主提供的受控浏览器能力，不借用 Shell、Node、curl、工作区写入或完整电脑访问。安装扩展只让能力进入目录；当前世界启用扩展、角色获得授权并通过具体动作审批后，受信任适配器才会访问外部网络。

```text
工作区安装扩展
        ↓
技能目录发现
        ↓
当前世界启用
        ↓
角色获得技能与工具授权
        ↓
具体网页动作只批准本次
        ↓
受控浏览器读取公开网页
        ↓
不可信外部事实进入角色回答
```

## 浏览能力

官方“只读网页浏览”扩展声明四项能力：

- 打开公开网页；
- 读取网页可见文本；
- 按明确选择器提取可见文本；
- 生成受限尺寸截图。

截图先写入世界的宿主管理缓存，再发布到世界产物中心；缓存随后清理。该流程不会写入角色的世界文件工作区。网页正文和截图都不能自动变成世界知识，仍需用户在产物或知识界面明确操作。

## 网络安全边界

浏览器动作只接受用户明确提供的 HTTP 或 HTTPS 地址，并采用以下限制：

- 拒绝本机、私网、链路本地、保留地址、特殊数字地址和解析到任一私网地址的域名；
- 拒绝 URL 凭据、敏感查询参数、文件地址、数据地址和脚本地址；
- 每次动作使用全新的非持久化浏览器上下文，不复用 Cookie、登录状态或缓存；
- DNS 在执行前完成校验，并把原始主机名固定到本次选定的公共 IP；浏览器禁用代理；
- 只允许原始主机的主文档，跨主机重定向、子资源、弹窗、脚本、WebSocket、EventSource、下载和非 GET/HEAD 请求全部阻断；
- 主文档、可见文本、选择器、超时、重定向、截图尺寸和截图字节数都有上限；
- 实际连接地址必须与固定的公共 IP 一致，无法验证时按失败或结果未知处理。

页面内容始终放在“不可信外部来源”边界内。网页中的“忽略规则”“执行命令”或伪造系统标记只是被读取的数据，不能成为宿主指令、工具结果或再次执行的依据。

## 三层权限

产品界面把权限分成三个连续但独立的层次：

1. 世界权限：读取或修改当前世界内的文件、设置、角色、知识和产物。
2. 技能与工具：浏览器、外部连接、MCP 和其他受信任适配器能力。
3. 本次电脑访问：只有所有者可确认，绑定当前世界、指定角色、具体消息、任务内容摘要和短有效期，消费一次后立即失效；确认后修改消息会撤销这次授权。

世界内读写不代表拥有浏览器或 Shell。浏览公开网页不要求完整电脑访问。完整电脑访问不再作为长期世界设置，也不能成为角色永久权限。

## 审批范围

审批界面只渲染服务端返回的 `allowedScopes`。范围由提供该能力的受信任描述决定，不由前端根据适配器名称猜测：

- 仅单次：网页浏览、Firecrawl、MCP 等参数会变化的动作；
- 精确目标：只有明确声明可复用精确目标策略的能力，才可以显示本角色或本世界持续允许。

不支持长期授权时，界面直接说明“当前仅支持本次批准”，不会先展示一个必然失败的按钮。

## 聊天命令与角色技能

聊天输入区的入口名称为“命令”，只显示需要用户主动触发的提示命令。自动提示转换和角色技能不会出现在命令列表中。选择命令只会填入输入框，不会绕过用户确认自动发送。

## 运行依赖

受控浏览器使用与项目锁定版本匹配的 Playwright Chromium。源码安装环境需执行：

```bash
pnpm exec playwright install chromium
```

缺少浏览器运行文件时，动作保持未执行并返回可诊断提示，不会回退到 Shell、系统浏览器或不受控网络请求。

## 验收

- 协议、私网、特殊 IP、DNS 固定、跨主机重定向、弹窗、非只读请求、下载、超时和大小限制均有正反测试；
- 未安装世界扩展、角色未授权或审批未通过时，不创建外部请求；
- 批准后只执行一次，真实结果进入同一工作回合；
- 截图进入世界产物中心并保留角色、工作回合和版本来源；
- 一次性电脑访问不可重放，不改变世界或角色长期权限；
- 1440×900、1920×1080、3840×2160 下审批卡、权限设置和确认弹窗无横向溢出，正文与操作文案保持中文且清晰可读。
