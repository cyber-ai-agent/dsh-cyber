# 世界侧栏动态页签 V1

右侧世界侧栏把高频上下文和低频工具分开，避免所有功能同时占据一级导航。

## 一级入口

“世界”和“轨迹”始终显示。“更多”始终固定在可见区域，不会随临时页签横向滚动。

“角色”“知识”“产物”“日程”位于“更多”菜单。选择其中一项后，该页面会成为一级临时页签，便于在当前工作中重复切换。

## 关闭与恢复

临时页签可以单独关闭。关闭只移除导航入口，不删除角色、知识、产物、日程或页面内状态。关闭当前页签时，侧栏返回最近使用且仍然存在的页签。

临时页签的打开顺序按世界保存在本机。重新加载应用会恢复当前世界的页签，不会把一个世界的侧栏状态带入另一个世界。

## 响应式与无障碍

临时页签区域可以横向滚动，“更多”和收起按钮保持可见。桌面操作目标不小于 40 像素，窄屏触控目标不小于 44 像素。

“更多”菜单支持方向键、Home、End 和 Escape。Escape 关闭菜单并把焦点送回“更多”。页签和关闭按钮均提供独立的中文可访问名称。

## 保持不变

- 世界切换继续隔离角色、知识、产物、轨迹和日程。
- 聊天中的产物引用和角色管理入口仍可直接打开对应临时页签。
- 知识库、知识图谱和产物阅读器的数据与加载边界不变。
- 文件与预览入口继续隐藏。
