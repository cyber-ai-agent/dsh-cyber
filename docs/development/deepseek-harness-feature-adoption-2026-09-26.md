# DSH 0.1.7 新能力与 DSH Cyber 融合

核对日期：2026-09-26。上游依据：[0.1.7-rc.1 汇总](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.7-rc.1)、[0.1.7-rc.2 修复](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.7-rc.2)与 [MCP Resources 规范/SDK 示例](https://github.com/modelcontextprotocol/typescript-sdk/blob/main/docs/servers/resources.md)。产品基线是本地 `stateRoot` 的世界、角色、会话、知识与授权事实。

| 上游能力 | DSH Cyber 决策 | 产品归属与验证 |
| --- | --- | --- |
| MCP 资源发现与读取 | **本轮引入**：知识库“导入资料 → 从 MCP 资源导入”。列出当前工作区已启用的连接和它们公布的资源；用户预览后显式导入当前世界。 | MCP 只提供只读数据。导入前按连接和世界校验，最多列 100 项、预览 8000 字、读取 1 MiB 文本；导入时重新读取并比对预览内容 SHA-256。二进制与未公布 URI 拒绝。源 URI 可能含凭据，因此持久资料只保存连接名和 URI 摘要，原文保存在当前世界知识库。 |
| 会话中启用新工具 | **沿用现有每轮重验**：角色当前 revision 和世界可用 Skill 每轮重新解析；稳定人格/技能说明变化时 Harness lane 重建，原会话仍是同一 canonical 会话，历史从本地消息重放。 | Skill Grant、世界包激活与具体动作审批仍由 DSH Cyber 掌管。运行中的单个回合暂不热插入工具，避免中途更换权限和重复副作用；下一回合生效。 |
| 长对话与长工具结果修复 | **随 SDK 升级吸收**，继续保留 DSH Cyber 自己的上下文预算、索引、水合与凭据值脱敏。 | 不将上游 Session 日志变为业务数据库；真实工具结果经过现有有界证据投影。长对话回归以准确性和输入预算共同验收。 |
| 上游提醒、Team 看板、插件管理 | **维持当前领域实现**：任务台计划/运行记录、群聊协作与 Skill 中心已有独立持久事实和审批链。 | 不复制一套上游待办表、角色权限或插件目录，避免同一世界出现两套真相。可借鉴交互方式，逐项实现于现有入口。 |
| Auto review 与 Computer Use | **暂不自动启用**：它们可能执行跨应用动作，需先映射到世界/角色/动作/目标的窄授权和审计。 | 后续先做单动作适配器与拒绝/超时恢复测试，再开放用户可见入口。 |
| 官方桌面版体验 | **建议 Windows 预览版**：复用现有 Server、Web 工作台和 `stateRoot`，先解决启动、托盘、后台任务、备份与更新。 | 安装、升级、回滚、卸载都必须证明不覆盖世界、角色、会话或本机加密凭据；macOS/Linux 在 Windows 闭环稳定后评估。 |

MCP 导入是用户发起的快照，不会自动订阅远端资源更新。再次导入同一连接和 URI 会更新同一世界内的本地资料；其他世界的知识库不受影响。资源正文按外部资料对待，不把其中的指令当作权限来源或可执行命令。

验收路径：安装/启用 MCP 连接 → 当前世界知识库真实可见的“从 MCP 资源导入” → 读取目录 → 预览 → 资源变化则拒绝导入 → 重新预览并导入 → 搜索/预览本地资料。覆盖跨工作区连接拒绝、二进制和超长文本拒绝、凭据 URI 不进入持久文件，并在 1440×900、1920×1080、3840×2160 检查布局、文字与控制台。
