# ADR 0001: World Runtime 与扩展边界

- 状态：Accepted
- 日期：2026-08-20

## 背景

DSH Cyber 同时需要独立 Agent 会话、可交互世界、员工成长、本地持久化以及可安装生态。若界面直接依赖 DeepSeek Harness 内部类型，或让主题、插件和人才包直接修改应用状态，上游更新、包升级和世界隔离都会变得不可验证。

## 决策

### 1. 世界是事件投影，不是独立动画脚本

World Runtime V2 使用版本化契约。Agent 运行事件和领域事件先写入 SQLite，再投影为角色、物件、会议、灯光和活动状态。Web 通过可恢复 SSE 接收增量，并可随时从持久化快照重建场景。

PixiJS 只负责渲染、命中测试、相机和动画；角色身份、任务结果和会话内容仍由应用服务与 Harness 适配器负责。

### 2. 员工是持久的独立 Agent

员工实例绑定工作区与世界，拥有自己的角色修订、模型策略和 Harness session。直接点名会进入该员工的真实会话；群聊由多个独立 Agent 依次发言。切换世界时不复用旧世界的会话或 `@` 候选。

### 3. 模型采用分层路由

模型资料不保存密钥，只保存凭据引用。用户直接填写的 API 密钥由本机服务使用随机密钥加密后存入独立凭据库；环境变量引用作为高级兼容方式保留。模型路由按以下顺序解析：员工、世界、工作区、默认资料。这样可以在保持工作区兜底配置的同时，为不同员工或世界分配不同供应商和模型。

### 4. 三类市场共享一种可审计包协议

主题市场、插件市场和人才市场都从独立目录加载包。每个包包含 `dsh-cyber.package.json`、逐文件 SHA-256、入口定义、能力声明、数据外发声明、发布者和许可证。

目录发现不代表信任。官方认证需要同时满足受信机构和内容摘要校验。安装前生成权限差异与一次性批准令牌，安装时再次校验文件，使用暂存目录激活；失败保留当前活动版本和回滚事务。

当前支持的真实入口包括：

- `prompt-transform`：在 Agent 回合开始前转换提示；当前严格限定为声明式 JSON，只改变 runtime prompt，持久化的原始用户消息不被改写；
- `employee-blueprint`：向指定世界提供可招聘员工蓝图；
- `world-theme`：提供版本化世界主题清单；
- `skill`：为后续 Harness Skill 授权与装载保留入口，当前尚未自动注入或授权。

当前不加载或执行第三方 JavaScript、TypeScript、原生模块或任意本机命令，也不提供网络代理、通用存储或可执行代码 sandbox。`talent` 是市场分类，不是包类型；员工蓝图包的 `kind` 必须是 `employee-blueprint`。官方认证同时要求受信机构与内容摘要一致，但 `certification` 不是密码学签名。

远程市场/索引、密码学签名、依赖解析、自动更新、卸载和 `package pack|verify|publish` 发布 CLI 均保留为路线图；当前只支持本地市场、安装前预览与可回滚安装。

### 5. Harness 只位于适配边界

产品领域、SQLite、市场协议和 Web 不直接导入 Harness 内部 API。Harness 更新先进入候选运行时，经过版本检查、合同测试、真实模型金丝雀和人工批准后才切换活动指针；失败可以从 CLI 回滚。

## 结果

- 世界状态可以回放、恢复和测试，而不是依赖浏览器中的随机行为。
- 上游 DSH 更新不会要求重写产品领域层。
- 插件安装具有真实运行效果，同时保持最小权限和可回滚性。
- 主题、插件、人才与未来模型 Provider 可以共享市场基础设施，但通过不同入口保持职责隔离。
- 云同步可以在未来复制加密的本地状态，而不改变 SQLite 作为本地权威数据源的地位。

## 非目标

- 当前 ADR 不定义复杂多 Agent 工作流编排；首阶段以直接会话和确定性群聊为主。
- 当前 ADR 不允许市场包执行任意本机脚本；新增可执行入口必须先扩展能力模型、沙箱和审计策略。
- 当前 ADR 不把发现到的开源包自动标记为可信或自动安装。
