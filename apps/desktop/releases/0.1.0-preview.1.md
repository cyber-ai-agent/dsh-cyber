# DSH Cyber Windows 桌面预览版 0.1.0-preview.1

这是 Windows x64 预发布版本。桌面壳运行与 Web 工作台相同的本地世界、角色、会话和任务，不新建业务数据库。

- [下载安装包](https://github.com/cyber-ai-agent/dsh-cyber/releases/download/desktop-v0.1.0-preview.1/DSH-Cyber-Setup-0.1.0-preview.1-win-x64.exe)
- [下载便携版 ZIP](https://github.com/cyber-ai-agent/dsh-cyber/releases/download/desktop-v0.1.0-preview.1/DSH-Cyber-Portable-0.1.0-preview.1-win-x64.zip)
- [下载 SHA-256 校验文件](https://github.com/cyber-ai-agent/dsh-cyber/releases/download/desktop-v0.1.0-preview.1/SHA256SUMS.txt)

支持单实例、托盘恢复、关闭窗口后后台继续运行，以及明确退出时停止本地服务。已有数据库首次由此桌面版本打开前会先生成完整 Backup Bundle；备份失败就不会启动。默认数据目录保持 `%LOCALAPPDATA%\DSH Cyber`，卸载程序不会清除世界和会话。详细说明见[桌面版文档](https://github.com/cyber-ai-agent/dsh-cyber/blob/main/apps/desktop/README.md)。

**预览限制：**安装包未签名，Windows 可能显示未知发布者提示；当前没有自动更新，请先从托盘退出旧进程，再安装下一版本。模型服务仍需自行配置。DSH Cyber 使用[非商业许可证](https://github.com/cyber-ai-agent/dsh-cyber/blob/main/LICENSE)；商业使用需要另行授权。
