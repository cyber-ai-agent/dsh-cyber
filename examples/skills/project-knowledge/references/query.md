# 有据问答

适用于回答项目进度、设计理由、决策依据、规则或历史变更。

## 检索范围

从问题中确定对象、时间点、版本和所需证据类型。先看已加载的相关来源；有获准检索能力时，用项目名、关键术语及必要别名缩小查询。只看到少量命中不等于读过所有资料。

搜索未命中时可以在相同授权范围内调整术语。停止于取得足够证据、相关来源已经检查完或读取能力不足，不把无限扩大检索当成解决缺口的方法。

## 判断证据

- 问当前实现：优先检查对应版本的实际代码、合同与运行证据。
- 问作出过什么决定：找决策记录和原始消息，区分提议、同意与已实施。
- 问历史变化：对齐各版本与有效时间，避免用今天的状态回答过去。
- 只有间接材料时：明确这是来源陈述或推断，不包装成亲自验证。

同一问题的来源相互矛盾时，不按命中数量投票。指出分别支持的内容、适用条件以及缺少哪项证据才能分辨；宿主已有的知识状态可以作为线索，不能替代原始证据。

## 回答

先给证据能够支持的答案，再提供关键来源的精确定位。将推断与资料明确陈述分开，必要时标注截至时间。

找不到证据时说“在本次检查的资料中未找到”，不能断言“从未决定”或“没有发生”。如果工具不提供全文，不能声称已核对全文。

一个合格的部分答案可以是：已确认的部分、相互冲突的部分、目前无法确认的部分，以及最能补足缺口的一份资料。不要为使回答完整而补造负责人、日期或承诺。
