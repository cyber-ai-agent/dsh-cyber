# 一致性检查

适用于检查用户指定的一组项目知识、摘要或决策记录。检查报告与修订行为分开；范围内未发现问题不能推出整个知识库一致。

## 检查项

1. 可追溯性：每个关键主张能否定位到实际可读取的来源；来源是否支持主张的全部内容。
2. 归属与范围：对象、项目、世界和版本是否匹配；同名对象是否被误合并。
3. 时间：区分记录时间与生效时间；是否把旧状态当成当前状态；没有更新时间不自动判为过期。
4. 冲突：两条说法是否确实针对相同对象和相同有效时间；存在明确替代决定还是尚不能分辨。
5. 重复：相同内容是否来自同一原始来源；摘要之间相互引用是否形成没有原始证据的循环。
6. 状态：提案、决定、执行结果与验收是否被混写；失败或部分完成是否被表述成全部成功。

## 结果记录

每项问题给出类别、受影响的主张、双方来源或缺失定位、影响和最小修正建议。无法打开的来源标记为“本次无法核查”，而不是直接断言它不存在或错误。

对于冲突，保留双方内容并说明差异。只有用户明确决定、可靠证据或宿主已确认的替代关系足够明确时，才建议将旧记录标为被取代。检查不会自动删除历史、合并实体或清理原始资料。

## 结束条件

报告已检查的范围与版本、发现的问题和未能检查的部分。若用户随后授权修订，应用最小修改，保留证据关系，再检查受影响记录；如果没有写入能力，提供可审阅修订稿。
